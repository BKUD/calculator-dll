# Calculator dll

Console calculator with support for dynamic plugins

---
## Description

Приложение умеет:

- Вычислять выражения с операциями: `+ - * / ^ ()`
- Поддерживать функции через плагины: `sin`, `cos`, `ln`, `deg`, `pow`, `sqrt` и любые другие плагины DLL
- Загружать плагины из папки `./plugins` во время выполнения (динамически)
- Обрабатывать ошибки, например деление на ноль или некорректные аргументы функций
  
Example:

```text
16 + 4 * (3 - 1) = 24
```
